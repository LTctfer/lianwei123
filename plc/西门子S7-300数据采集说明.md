# 西门子S7-300 Modbus TCP/IP数据采集系统

## 系统概述

本系统专门针对西门子S7-300系列PLC，通过Modbus TCP/IP协议读取监测站数据。系统完全按照西门子官方Modbus TCP/IP协议规范实现，支持S7-300的特殊地址映射和数据格式。

## 🏭 西门子S7-300特点

### 地址映射
- **I区 (输入区)**: 传感器输入数据
- **Q区 (输出区)**: 控制输出数据  
- **M区 (标志区)**: 内部标志和临时数据
- **DB区 (数据块)**: 结构化数据存储

### 数据类型
- **BOOL**: 布尔值 (1位)
- **BYTE**: 字节 (8位无符号)
- **WORD**: 字 (16位无符号)
- **DWORD**: 双字 (32位无符号)
- **INT**: 整数 (16位有符号)
- **DINT**: 双整数 (32位有符号)
- **REAL**: 实数 (32位IEEE754浮点数)

### 字节序
- 西门子S7-300使用**大端序 (Big-Endian)**
- 高字节在前，低字节在后

## 🚀 快速开始

### 1. S7-300 Modbus配置

在S7-300中需要配置Modbus TCP服务器：

```
1. 在STEP 7中打开项目
2. 配置CP343-1模块的IP地址
3. 启用Modbus TCP服务器功能
4. 设置Modbus地址映射
5. 下载配置到PLC
```

### 2. 修改连接配置

编辑 `s7_config.json`:

```json
{
  "plc_settings": {
    "host": "192.168.1.100",    // S7-300的IP地址
    "port": 502,                // Modbus TCP端口
    "unit_id": 1,               // 单元ID
    "timeout": 5.0,             // 连接超时
    "plc_type": "S7-300"        // PLC类型
  }
}
```

### 3. 配置数据映射

```json
{
  "registers": [
    {
      "name": "pm25",
      "address": "DB1.DBD0",     // 数据块1，双字偏移0
      "data_type": "REAL",       // 32位浮点数
      "scale": 1.0,
      "offset": 0.0,
      "unit": "μg/m³"
    }
  ]
}
```

### 4. 运行采集程序

```bash
# 测试连接
python plc_data_collector.py --config s7_config.json --test

# 开始采集
python plc_data_collector.py --config s7_config.json --interval 60
```

## 📊 S7地址格式说明

### 数据块地址 (DB区)

| 格式 | 说明 | 示例 |
|------|------|------|
| DB1.DBD0 | 数据块1，双字偏移0 | 32位浮点数 |
| DB1.DBW8 | 数据块1，字偏移8 | 16位整数 |
| DB1.DBB16 | 数据块1，字节偏移16 | 8位数据 |
| DB1.DBX18.0 | 数据块1，字节18位0 | 布尔值 |

### 标志区地址 (M区)

| 格式 | 说明 | 示例 |
|------|------|------|
| MD0 | 标志区双字0 | 32位数据 |
| MW0 | 标志区字0 | 16位数据 |
| MB0 | 标志区字节0 | 8位数据 |
| MX0.0 | 标志区字节0位0 | 布尔值 |

### 输入/输出区地址

| 格式 | 说明 | 示例 |
|------|------|------|
| IW0 | 输入区字0 | 模拟量输入 |
| QW0 | 输出区字0 | 模拟量输出 |
| IX0.0 | 输入区字节0位0 | 数字量输入 |
| QX0.0 | 输出区字节0位0 | 数字量输出 |

## 🔧 Modbus地址映射

系统自动将S7地址转换为Modbus地址：

```
I区基址: 0
Q区基址: 512  
M区基址: 4096
DB区基址: 8192 + DB号*1000
```

### 映射示例

| S7地址 | Modbus地址 | 说明 |
|--------|------------|------|
| DB1.DBW0 | 9192 | 8192+1*1000+0 |
| DB1.DBD4 | 9196 | 8192+1*1000+4 |
| MW10 | 4106 | 4096+10 |
| IW0 | 0 | 0+0 |
| QW2 | 514 | 512+2 |

## 🛠️ 使用示例

### 基本读取

```python
from modbus_plc_reader import S7DataReader, S7Register

# 创建S7读取器
reader = S7DataReader(host="192.168.1.100")

# 添加寄存器
temp_reg = S7Register(
    name="temperature",
    address="DB1.DBD0",
    data_type="REAL",
    unit="°C"
)
reader.add_register(temp_reg)

# 连接并读取
if reader.connect():
    data = reader.read_all_registers()
    print(f"温度: {data['temperature']['value']} °C")
    reader.disconnect()
```

### 批量采集

```python
from plc_data_collector import S7DataCollector

# 创建采集器
collector = S7DataCollector("s7_config.json")

# 测试连接
if collector.test_connection():
    # 开始连续采集
    collector.start_continuous_collection(interval=30)
```

## 🚨 常见问题

### 1. 连接失败
- 检查S7-300的IP地址和网络连通性
- 确认CP343-1模块配置正确
- 验证Modbus TCP服务是否启用

### 2. 地址错误
- 确认S7地址格式正确
- 检查数据块是否存在
- 验证地址映射配置

### 3. 数据类型错误
- 确认S7数据类型与配置匹配
- 检查字节序设置
- 验证缩放因子和偏移量

### 4. 读取超时
- 增加连接超时时间
- 检查网络延迟
- 减少单次读取的数据量
