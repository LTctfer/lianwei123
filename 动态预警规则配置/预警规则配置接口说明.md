# 预警规则配置接口说明

## 1. 接口概览

后端提供以下 HTTP 接口用于管理预警规则：

- `GET /get_config`: 获取当前规则配置
- `POST /sync_rules`: 批量更新规则配置
- `GET /alarms`: 查看已触发的预警记录
- `POST /push_alarm`: 接收预警数据（预警引擎调用）

服务地址：`http://localhost:8000`

## 2. 接口详细说明

### 2.1 获取当前规则配置

```http
GET /get_config
```

**响应示例：**
```json
{
  "rules": [
    {
      "alarmRuleId": "R001",
      "alarmRuleName": "设备温度预警",
      "alarmClazz": "DEVICE_ALARM",
      ...
    }
  ]
}
```

### 2.2 更新规则配置（完全覆盖模式）

```http
POST /sync_rules
Content-Type: application/json
```

该接口采用完全覆盖模式，新的规则配置将完全替换现有的所有规则。

**请求体格式：**
```json
{
  "rules": [
    {
      "alarmRuleId": "规则ID",
      "alarmRuleName": "规则名称",
      "alarmClazz": "预警类别",
      "alarmType": "预警类型",
      "alarmLevel": "预警级别",
      "alarmInternal": "预警间隔（小时）",
      "dataInternal": "数据间隔",
      "enabled": 1,
      "showProperties": ["要显示的属性列表"],
      "config": {
        "singlePropertyRule": [
          {
            "symbol": "OR/AND",
            "property": "属性名",
            "lowValue": "下限值",
            "highValue": "上限值",
            "expression1": "比较符号",
            "expression2": "比较符号"
          }
        ],
        "doublePropertyRule": [
          {
            "leftProperty": "左属性",
            "rightProperty": "右属性",
            "expression": "比较符号"
          }
        ],
        "workStatus": ["工况1", "工况2"],
        "frequency": {
          "enabled": 1,
          "hasAccumulate": 0,
          "continuousCount": 2,
          "accumulateCount": 3,
          "accumulateTimeRange": 30
        }
      }
    }
  ]
}
```

**响应示例：**
```json
{
  "success": true,
  "old_count": 2,
  "new_count": 1,
  "message": "原有 2 条规则已被 1 条新规则完全覆盖"
}
```

### 2.3 查看预警记录

```http
GET /alarms
```

**响应示例：**
```json
{
  "count": 2,
  "items": [
    {
      "alarmId": "R001",
      "alarmTime": "2025-10-10 14:32:55",
      "data": {
        "temperature": 95.3
      },
      "receivedAt": "2025-10-10 14:32:55"
    }
  ]
}
```

## 3. 调用示例

### 3.1 使用 curl 命令

1. 获取当前配置：
```bash
curl http://localhost:8000/get_config
```

2. 更新规则配置：
```bash
curl -X POST http://localhost:8000/sync_rules \
  -H "Content-Type: application/json" \
  -d @config.json
```

3. 查看预警记录：
```bash
curl http://localhost:8000/alarms
```

### 3.2 使用 Python requests

1. 获取当前配置：
```python
import requests

response = requests.get('http://localhost:8000/get_config')
print(response.json())
```

2. 更新规则配置（完全覆盖现有规则）：
```python
import requests
import json
from pprint import pprint

# 准备新的规则配置
new_config = {
    "rules": [
        {
            "alarmRuleId": "NEW001",
            "alarmRuleName": "新温度预警",
            "alarmClazz": "DEVICE_ALARM",
            "alarmType": "1",
            "alarmLevel": "HIGH",
            "alarmInternal": 2,
            "dataInternal": "2h",
            "enabled": 1,
            "showProperties": ["temperature"],
            "config": {
                "singlePropertyRule": [
                    {
                        "symbol": "OR",
                        "property": "temperature",
                        "lowValue": 15,
                        "expression1": "lt",
                        "highValue": 85,
                        "expression2": "gt"
                    }
                ],
                "doublePropertyRule": [],
                "frequency": {
                    "enabled": 1,
                    "hasAccumulate": 1,
                    "accumulateCount": 5,
                    "accumulateTimeRange": 600
                }
            }
        }
    ]
}

# 发送到后端（将完全覆盖现有规则）
response = requests.post(
    'http://localhost:8000/sync_rules',
    json=new_config
)
pprint(response.json())  # 显示覆盖结果
```

3. 查看预警记录：
```python
import requests

response = requests.get('http://localhost:8000/alarms')
print(response.json())
```

### 3.3 使用管理工具

## 4. 规则配置说明

### 4.1 预警规则参数

| 参数 | 说明 | 类型 | 示例值 |
|------|------|------|--------|
| alarmRuleId | 规则ID | string | "R001" |
| alarmRuleName | 规则名称 | string | "设备温度预警" |
| alarmClazz | 预警类别 | string | "DEVICE_ALARM" |
| alarmType | 预警类型 | string | "1" |
| alarmLevel | 预警级别 | string | "HIGH" |
| alarmInternal | 预警间隔（小时） | number | 1 |
| enabled | 是否启用 | number | 1 |
| showProperties | 要显示的属性 | array | ["temperature"] |

### 4.2 预警条件配置

1. 单属性规则：
```json
{
  "symbol": "OR",
  "property": "temperature",
  "lowValue": 20,
  "expression1": "lt",
  "highValue": 90,
  "expression2": "gt"
}
```

2. 双属性规则：
```json
{
  "leftProperty": "t1",
  "rightProperty": "t2",
  "expression": "gt"
}
```

### 4.3 频率控制

```json
{
  "enabled": 1,
  "hasAccumulate": 0,
  "continuousCount": 2,
  "accumulateCount": 3,
  "accumulateTimeRange": 30
}
```

- `hasAccumulate`: 0表示连续触发，1表示累计触发
- `continuousCount`: 连续触发次数
- `accumulateCount`: 累计触发次数
- `accumulateTimeRange`: 累计时间范围（秒）

## 5. 注意事项

1. 确保规则ID唯一
2. 修改规则后预警引擎会自动加载新规则
3. 所有时间戳格式为：`YYYY-MM-DD HH:mm:ss`
4. 比较符号支持：lt(<), le(<=), eq(=), ge(>=), gt(>)
5. 工况状态仅对 ENTERPRISE_ALARM 类型有效
6. 修改规则后建议查看预警记录确认是否生效
7. **规则更新机制**：
   - 调用 `/sync_rules` 接口会完全覆盖现有规则
   - 新规则会替换所有旧规则，而不是增量更新
   - 更新后会返回新旧规则的数量对比
   - 建议在更新前先获取当前配置进行备份
