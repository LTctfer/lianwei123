# 动态预警规则配置系统 - 使用说明

## 📋 系统概述

这是一个精简高效的预警规则引擎，支持动态配置、频率控制和实时预警。系统包含累积异常次数和连续异常次数两种频率控制模式，能够准确控制预警触发频率。

## ⚙️ 核心功能

### 1. 频率控制模式

#### 累积模式 (hasAccumulate=1)
- **功能**: 在指定时间窗口内累积异常次数
- **配置**: `accumulateCount=5, accumulateTimeRange=30`
- **行为**: 30分钟内累积5次异常才触发预警
- **适用场景**: 偶发异常过滤，避免误报

#### 连续模式 (hasAccumulate=0)
- **功能**: 连续异常次数控制
- **配置**: `continuousCount=3`
- **行为**: 连续3次异常才触发预警，正常数据重置计数
- **适用场景**: 持续异常检测，快速响应

### 2. 规则类型

#### 单属性规则
```toml
[[device_alarm_config.singlePropertyRule]]
symbol = "OR"
property = "t1"
lowValue = 1
expression1 = "lt"    # t1 < 1 (过小)
highValue = 10
expression2 = "gt"    # t1 > 10 (过大)
```

#### 双属性规则
```toml
[[device_alarm_config.doublePropertyRule]]
symbol = "AND"
leftProperty = "t1"
rightProperty = "t2"
expression = "lt"     # t1 < t2 触发异常
```

## 🔧 配置示例

### 累积模式配置
```toml
[device_alarm_config.frequency]
enabled = 1
hasAccumulate = 1          # 累积模式
accumulateCount = 5        # 累积5次
accumulateTimeRange = 30   # 30分钟窗口
```

### 连续模式配置
```toml
[device_alarm_config.frequency]
enabled = 1
hasAccumulate = 0          # 连续模式
continuousCount = 3        # 连续3次
```

## 📝 使用示例

### 基本使用
```python
from compact_alarm_engine import CompactAlarmEngine

# 创建引擎
engine = CompactAlarmEngine()

# 处理数据
data = {'t1': 0.1, 't2': 25, 't3': 50, 't4': 5}
alarm = engine.process_data(data)

if alarm:
    print(f"触发预警: {alarm['alarmId']}")
    print(f"预警等级: {alarm['alarmInfo']['alarmLevel']}")
```

### 频率控制测试
```python
# 累积模式测试
for i in range(5):
    alarm = engine.process_data(abnormal_data)
    if i < 4:
        assert alarm is None  # 前4次不触发
    else:
        assert alarm is not None  # 第5次触发

# 连续模式测试
engine.process_data(abnormal_data)  # 第1次
engine.process_data(abnormal_data)  # 第2次
engine.process_data(normal_data)    # 重置计数
alarm = engine.process_data(abnormal_data)  # 重新开始计数
assert alarm is None
```

### 配置动态修改
```python
from alarm_rule_manager import AlarmRuleManager

manager = AlarmRuleManager()

# 修改频率控制参数
manager.update_config({
    "device_alarm_config.frequency.accumulateCount": 3,
    "device_alarm_config.frequency.accumulateTimeRange": 15
})

# 修改预警等级
manager.update_config({
    "alarm_rule.alarmLevel": "MEDIUM"
})

# 修改时间范围
manager.update_config({
    "alarm_rule.startTime": "08:00",
    "alarm_rule.endTime": "18:00"
})
```
