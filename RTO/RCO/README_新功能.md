# RTO/RCO预警系统功能升级说明

## 新增功能概览

本次升级在原有预警系统基础上，新增了以下核心功能：

### 1. 🧹 数据清洗可视化对比

#### 功能描述
通过箱线图对比数据清洗前后的效果，直观展示数据质量的改善。

#### 核心特性
- **对比展示**: 清洗前后数据分布的并列对比
- **多维度分析**: 支持所有数值型字段的清洗效果展示
- **统计信息**: 显示清洗前后数据量变化
- **图片保存**: 自动保存高清对比图到指定目录

#### 使用方法
```python
# 自动调用（数据清洗完成后）
df_clean = cleaner.clean_data(df)

# 手动调用
cleaner.visualize_cleaning_process(df_original, df_cleaned)
```

### 2. 📊 优化实时趋势图

#### 功能描述
增强趋势图功能，添加阈值线显示和超标数据点标红。

#### 核心特性
- **阈值线显示**: 红色虚线标示各参数的安全阈值
- **超标标红**: 超过阈值的数据点自动标记为红色
- **坐标轴优化**: 完整的X轴、Y轴标注
- **实时更新**: 每2秒刷新最新数据

#### 阈值配置
```javascript
const thresholdMap = {
    'temperature_combustion': 760,    // 燃烧室温度 ℃
    'temperature_outlet': 60,         // 出口温度 ℃
    'concentration_out': 50,          // 出口浓度 mg/m³
    'efficiency': 90,                 // 处理效率 %
    // ... 更多参数
};
```

### 3. 🎛️ 趋势图下拉框选择

#### 功能描述
提供12种不同数据类型的趋势图切换功能。

#### 支持的数据类型
1. **温度类**: 燃烧室温度、出口温度、吸附温度、脱附温度、反应器出口温度
2. **浓度类**: 进口浓度、出口浓度、颗粒物含量
3. **效率类**: 处理效率
4. **压力类**: 系统压力、催化压力损失
5. **流量类**: 流量

#### 使用方法
- 在大屏界面选择"实时趋势"面板
- 通过下拉框切换不同数据类型
- 实时查看对应参数的变化趋势

### 4. 🔄 报警周期聚合

#### 功能描述
将连续发生的同类型报警聚合为单条记录，显示持续时间和报警次数。

#### 聚合规则
- **时间窗口**: 5分钟内的连续报警视为同一周期
- **类型匹配**: 相同类型和设备的报警才会聚合
- **数值更新**: 保留最大报警值作为代表值

#### 显示信息
```python
{
    'type': '燃烧室温度不达标',
    'start_time': '2024-01-01 10:00:00',
    'end_time': '2024-01-01 10:15:00',
    'duration': 15.0,        # 持续时间(分钟)
    'count': 8,              # 报警次数
    'max_value': 750,        # 最大异常值
    'equipment': '燃烧室'
}
```
