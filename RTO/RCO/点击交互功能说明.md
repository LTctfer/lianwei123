**点击后显示：**

**点击后显示：**
- 完整报警历史表格

## 🚀 使用方法

### 启动系统
```bash
python warning_system.py
```
选择选项 `2` 启动实时监控大屏

### 访问地址
```
http://localhost:8090
```

### 操作步骤
1. **等待数据加载**: 系统启动后等待2-3秒
2. **点击任意模块**: 点击任何面板查看详情
3. **查看详细信息**: 弹窗显示完整数据表格
4. **关闭弹窗**: 点击X或外部区域关闭
5. **继续交互**: 可以点击其他模块

### 状态判断逻辑
- **燃烧室温度**: < 760℃ 为异常
- **出口温度**: > 60℃ 为异常
- **出口浓度**: > 50mg/m³ 为异常
- **吸附温度**: > 40℃ 为异常
- **脱附温度**: < 90℃ 或 > 120℃ 为异常
- **反应器温度**: > 600℃ 为异常
- **压力损失**: > 2kPa 为异常
- **颗粒物**: > 10mg/m³ 为异常
- **应急阀门**: > 0 为异常

## 🚨 故障排除

### 常见问题

**Q: 点击后没有弹窗？**
A: 检查浏览器控制台是否有JavaScript错误

**Q: 弹窗内容为空？**
A: 等待数据加载完成后再点击

**Q: 数据显示不正确？**
A: 刷新页面重新加载数据

**Q: 弹窗无法关闭？**
A: 点击X按钮或弹窗外部区域

### 调试方法
1. **F12开发者工具**: 查看控制台错误
2. **网络面板**: 检查API请求
3. **元素面板**: 检查HTML结构
4. **控制台**: 查看JavaScript日志
