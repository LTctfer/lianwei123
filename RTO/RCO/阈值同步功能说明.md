# 阈值同步功能实现说明

## 问题描述
通过前端界面修改预警规则阈值后，各个存在对阈值数值描述的界面未及时更新，包括：
- 实时趋势图中的阈值线
- 参数详情中的正常范围数值
- 预警规则管理中的描述信息

## 解决方案

### 2. 前端阈值缓存机制
在前端添加了阈值缓存，定期从API获取最新阈值：

```javascript
let thresholdsCache = {}; // 缓存阈值信息

async function fetchThresholds() {
    const response = await fetch('/api/rules/thresholds');
    const result = await response.json();
    if (result.success) {
        thresholdsCache = result.data;
    }
}

// 初始化时获取阈值，每10秒更新一次
fetchThresholds();
setInterval(fetchThresholds, 10000);
```

## 技术特点

### 1. 实时同步
- 阈值更新后立即同步到所有相关界面
- 无需刷新页面即可看到更新效果

### 2. 缓存机制
- 前端缓存阈值信息，减少API调用
- 定期更新缓存，确保数据一致性

### 3. 回退机制
- 当API获取失败时，回退到硬编码的默认值
- 保证系统稳定运行

### 4. 性能优化
- 阈值信息每10秒更新一次，平衡实时性和性能
- 只在需要时进行API调用
