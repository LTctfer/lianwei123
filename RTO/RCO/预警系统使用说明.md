# 废气处理设备预警系统使用说明

## 系统概述

本预警系统专门针对废气处理设备设计，具备完整的数据清洗、预警规则检测和可视化功能。系统能够自动检测17种常见的设备异常情况，并生成详细的违规记录和可视化报告。

## 🚀 快速开始

### 1. 环境准备

```bash
# 安装依赖库
pip install pandas numpy matplotlib seaborn openpyxl

# 或使用requirements.txt
pip install -r requirements.txt
```

### 2. 运行测试

```bash
# 运行完整测试
python test_warning_system.py

# 运行主程序
python warning_system.py
```

### 3. 使用自己的数据

```python
from warning_system import WarningSystem

# 创建预警系统
warning_system = WarningSystem()

# 分析数据文件 (支持xlsx, csv格式)
warning_system.run_analysis("your_data.xlsx")
```

## 📊 数据格式要求

|------|------|------|--------|

## 🚨 预警规则详解

### 1. 燃烧室相关 (R001)
- **规则**: 燃烧室温度 < 760℃
- **严重程度**: 高
- **说明**: 温度不达标会导致废气提前进入处理系统

### 2. 污染物浓度 (R002)
- **规则**: 出口污染物浓度 > 50 mg/m³
- **严重程度**: 严重
- **说明**: 超标排放，环保风险极高

### 3. 应急阀门 (R003)
- **规则**: 应急阀门 = 开启状态
- **严重程度**: 严重
- **说明**: 违规开启应急阀门

### 4. 处理效率 (R004)
- **规则**: 处理效率 < 90%
- **严重程度**: 高
- **计算**: 效率 = 1 - (出口浓度/进口浓度)

### 5. 出口温度 (R005)
- **规则**: 废气出口温度 > 60℃
- **严重程度**: 中
- **说明**: 出口温度过高

### 6. 吸附温度 (R007)
- **规则**: 吸附温度 > 40℃
- **严重程度**: 中
- **说明**: 吸附效果下降

### 7. 脱附温度 (R008)
- **规则**: 脱附温度 < 90℃ 或 > 120℃
- **严重程度**: 中
- **说明**: 脱附温度异常

### 8. 反应器温度 (R016)
- **规则**: 反应器出口温度 > 600℃
- **严重程度**: 严重
- **说明**: 需要自动开启冲稀设施

## 🧹 数据清洗功能

### 自动清洗规则

1. **负值处理**: 自动将负值设为NaN
2. **零值处理**: 关键参数的零值设为NaN
3. **异常值检测**: 使用IQR方法检测异常值
4. **数据填充**: 使用前向填充方法补充缺失值

### 清洗日志

系统会详细记录清洗过程：
```
温度列: 原始1000 → 清洗后950 (负值:10, 零值:5, 异常值:35)
浓度列: 原始1000 → 清洗后980 (负值:8, 零值:3, 异常值:9)
```

## 📈 可视化功能

### 1. 违规时间线图
- 显示所有违规事件的时间分布
- 按严重程度用不同颜色标识
- 便于识别违规集中时段

### 2. 严重程度分布图
- 饼图显示各严重程度占比
- 柱状图显示具体数量
- 帮助评估整体风险水平

### 3. 设备违规统计图
- 横向柱状图显示各设备违规次数
- 识别问题设备和薄弱环节

### 4. 违规持续时间分析
- 直方图显示违规持续时间分布
- 各规则平均持续时间对比
- 评估问题严重程度

## 📋 违规记录管理

### 记录生成规则

- **开始记录**: 检测到违规行为时创建新记录
- **持续更新**: 违规持续期间更新最大值、最小值
- **结束记录**: 违规行为结束时计算持续时间
- **状态管理**: ongoing(进行中) / resolved(已解决)

### 记录内容

每条违规记录包含：
- 记录ID、规则ID、规则名称
- 开始时间、结束时间、持续时间
- 最大值、最小值、平均值
- 严重程度、状态、影响设备

## 🔧 使用示例

### 基本使用

```python
from warning_system import WarningSystem

# 创建系统实例
system = WarningSystem()

# 分析数据
violations, summary = system.process_data_file("data.xlsx")

# 显示结果
print(f"发现 {len(violations)} 个违规事件")
print(f"总违规次数: {summary['total']}")
```

### 自定义分析

```python
from warning_system import DataCleaner, WarningRuleEngine

# 只进行数据清洗
cleaner = DataCleaner()
df = cleaner.load_data("data.xlsx")
df_clean = cleaner.clean_data(df)

# 只进行预警检测
engine = WarningRuleEngine()
violations = engine.check_rules(df_clean)
```

### 批量处理

```python
import glob

system = WarningSystem()

# 处理多个文件
for file_path in glob.glob("data/*.xlsx"):
    print(f"处理文件: {file_path}")
    system.run_analysis(file_path)
```
