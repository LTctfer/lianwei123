# PLC通信协议从S7修改为Modbus的代码变更总结

## 修改概述

本次修改将原有的西门子S7-200 Smart通信协议更改为标准的Modbus TCP协议，以支持更广泛的PLC设备。主要变更包括通信库、数据结构、地址映射和配置文件等方面。

## 1. 核心库变更

### 1.1 通信库替换
```python
# 原S7通信库
import snap7

# 新Modbus通信库
from pymodbus.client.sync import ModbusTcpClient
from pymodbus.constants import Endian
from pymodbus.payload import BinaryPayloadDecoder
```


## 3. 地址映射变更

### 3.1 S7地址 → Modbus地址映射

| 数据类型 | S7地址格式 | Modbus地址 | 功能码 | 说明 |
|---------|-----------|-----------|--------|------|
| 浮点数 | DB1.DBD0 | 40001-40002 | 03 | 32位浮点数占用2个寄存器 |
| 浮点数 | DB1.DBD4 | 40003-40004 | 03 | 振动Y轴数据 |
| 浮点数 | DB1.DBD8 | 40005-40006 | 03 | 振动Z轴数据 |
| 布尔值 | DB1.DBX60.0 | 1 | 01 | 设备运行状态线圈 |
| 布尔值 | DB1.DBX60.1 | 2 | 01 | 设备报警状态线圈 |

### 3.2 数据点配置示例
```yaml

  address: "DB1.DBD0"
  type: "REAL"
  unit: "mm/s"

# Modbus配置格式

  address: 40001
  type: "FLOAT32"
  function_code: 3
  unit: "mm/s"
```

## 4. 连接方法变更

### 4.1 连接建立
```python
# S7连接方法
def connect(self) -> bool:
    self.client.connect(self.config.ip_address, self.config.rack, self.config.slot)
    return self.client.get_connected()

# Modbus连接方法
def connect(self) -> bool:
    connection = self.client.connect()
    return connection
```

### 4.2 连接状态检查
```python
# S7状态检查
if self.client.get_connected():
    # 执行操作

# Modbus状态检查
if self.client.is_socket_open():
    # 执行操作
```

## 5. 数据读取方法变更

### 5.1 S7数据读取
```python
# 读取数据块
data = self.client.db_read(db_number, start, size)

# 解析地址
db_number, offset, size, addr_type = self.parse_address(address)

# 数据转换
value = struct.unpack('>f', data[offset:offset+4])[0]
```

### 5.2 Modbus数据读取
```python
# 读取保持寄存器
result = self.client.read_holding_registers(address, count, unit=self.config.unit_id)
registers = result.registers

# 读取线圈
result = self.client.read_coils(address, count, unit=self.config.unit_id)
coils = result.bits

# FLOAT32数据转换
combined = (registers[0] << 16) | registers[1]
packed = struct.pack('>I', combined)
value = struct.unpack('>f', packed)[0]
```

## 6. 错误处理变更

### 6.1 S7错误处理
```python
try:
    data = self.client.db_read(1, 0, 4)
    if data:
        # 处理数据
except Exception as e:
    logger.error(f"S7读取失败: {e}")
```

### 6.2 Modbus错误处理
```python
try:
    result = self.client.read_holding_registers(40001, 2, unit=1)
    if not result.isError():
        # 处理数据
    else:
        logger.error(f"Modbus读取失败: {result}")
except Exception as e:
    logger.error(f"Modbus异常: {e}")
```

## 13. 迁移建议

1. **逐步迁移**: 先在测试环境验证Modbus通信
2. **备份原代码**: 保留S7版本作为备份
3. **配置验证**: 确认PLC的Modbus寄存器映射正确
4. **功能测试**: 验证所有数据点读取正常
5. **性能测试**: 确认数据读取频率满足要求

## 14. 注意事项

1. **字节序**: Modbus默认使用大端序，需要注意数据转换
2. **地址偏移**: Modbus地址通常从1开始，而不是0
3. **数据类型**: FLOAT32需要占用2个连续寄存器
4. **错误处理**: Modbus有专门的错误码，需要正确处理
5. **超时设置**: Modbus TCP的超时时间通常以秒为单位

这次修改使系统具有更好的通用性和兼容性，能够支持更多品牌的PLC设备，降低了部署成本和维护难度。
