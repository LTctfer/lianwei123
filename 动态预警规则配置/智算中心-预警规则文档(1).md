

# 预警系统数据格式文档

## 一. 设备异常预警规则下发

### 主题
`command/{设备编号}`

### 命令数据格式

| 字段名         | 类型     | 必填  | 描述     | 示例值              |
| ----------- | ------ | --- | ------ | ---------------- |
| commandType | string | 是   | 指令类型   | ALARM_RULE(预警规则) |
| data        | object | 是   | 规则数据主体 | 见下表              |

json格式:
~~~json
{"commandType":"ALARM_RULE",data:{}}
~~~

#### 1. 预警规则指令data对象字段

| 字段名            | 类型      | 必填  | 描述                                                                                                                                                                     | 示例值            |
| -------------- | ------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------- |
| alarmRuleId    | string  | 是   | 预警规则ID                                                                                                                                                                 | "123456"       |
| alarmRuleName  | string  | 是   | 预警规则名称                                                                                                                                                                 | "温度异常预警"       |
| alarmClazz     | string  | 是   | 预警类别(离线预警、企业违规预警、设备异常预警)                                                                                                                                               | "DEVICE_ALARM" |
| alarmType      | string  | 是   | 预警类型                                                                                                                                                                   | "1"            |
| alarmLevel     | string  | 是   | 预警等级                                                                                                                                                                   | "HIGH"         |
| alarmInternal  | integer | 是   | 预警间隔时长(小时)                                                                                                                                                             | 2              |
| dataInternal   | string  | 是   | 数据时间间隔                                                                                                                                                                 | "1h"           |
| algorithmType  | string  | 是   | 关联算法类型                                                                                                                                                                 | "test"         |
| calculateWay   | string  | 是   | 计算方式                                                                                                                                                                   | "test"         |
| enabled        | integer | 是   | 是否启用(0:禁用,1:启用)                                                                                                                                                        | 1              |
| startTime      | string  | 是   | 预警开始时间(HH:mm格式)                                                                                                                                                        | "08:00"        |
| endTime        | string  | 是   | 预警结束时间(HH:mm格式)                                                                                                                                                        | "18:00"        |
| showProperties | array   | 是   | 关联展示属性列表                                                                                                                                                               | ["1","2"]      |
| config         | object  | 是   | 预警配置(JSON字符串格式，包含具体的预警规则配置信息)预警配置(JSON字符串格式)。根据alarmClazz值不同，内容结构不同：<br>1. 当alarmClazz="DEVICE_ALARM"时，为设备异常预警的配置格式<br>2. 当alarmClazz="ENTERPRISE_ALARM"时，为企业违规预警的配置格式 |                |

json格式：
~~~json
{
  "alarmRuleId": "123456",
  "alarmRuleName": "温度异常预警",
  "alarmClazz": "DEVICE_ALARM",
  "alarmType": "1",
  "alarmLevel": "HIGH",
  "alarmInternal": 2,
  "dataInternal": "1h",
  "algorithmType": "test",
  "calculateWay": "test",
  "enabled": 1,
  "startTime": "08:00",
  "endTime": "18:00",
  "showProperties": ["1", "2"],
  "config": ""
}
~~~
#### 2. 设备异常预警config字段描述

| 字段名                | 类型     | 必填  | 描述            | 示例值 |
| ------------------ | ------ | --- | ------------- | --- |
| singlePropertyRule | array  | 是   | 设备异常告警单属性规则列表 | -   |
| doublePropertyRule | array  | 是   | 设备异常告警双属性规则列表 | -   |
| frequency          | object | 是   | 设备异常告警频率配置    | -   |
##### (1)singlePropertyRule内元素字段描述

| 字段名         | 类型     | 必填  | 描述                                       | 示例值  |
| ----------- | ------ | --- | ---------------------------------------- | ---- |
| symbol      | string | 是   | 逻辑符号(AND/OR)                             | "OR" |
| property    | string | 是   | 属性名称                                     | "t1" |
| lowValue    | number | 是   | 最小值                                      | 1    |
| expression1 | string | 是   | 最小值比较表达式("lt"(小于), "le"(小于等于), "eq"(等于)) | "lt" |
| highValue   | number | 是   | 最大值                                      | 10   |
| expression2 | string | 是   | 最大值比较表达式("lt"(小于), "le"(小于等于), "eq"(等于)) | "<"  |

##### (2)doublePropertyRule 内元素字段描述

| 字段名           | 类型     | 必填  | 描述                                                           | 示例值   |
| ------------- | ------ | --- | ------------------------------------------------------------ | ----- |
| symbol        | string | 是   | 逻辑符号(AND/OR)                                                 | "AND" |
| leftProperty  | string | 是   | 左侧属性名称                                                       | "t1"  |
| rightProperty | string | 是   | 右侧属性名称                                                       | "t2"  |
| expression    | string | 是   | 比较表达式(如"eq"(等于), "lt"(小于), "le"(小于等于), "gt"(大于), "ge"(大于等于)) | "lt"  |
##### (3)frequency 字段描述

| 字段名                 | 类型      | 必填  | 描述                          | 示例值 |
| ------------------- | ------- | --- | --------------------------- | --- |
| enabled             | integer | 是   | 是否启用(0:禁用,1:启用)             | 1   |
| hasAccumulate       | integer | 是   | 是否累计(1:启用累计异常次数,0:启用连续异常次数) | 1   |
| accumulateCount     | integer | 否   | 累计异常次数(当hasAccumulate=1时必填) | 5   |
| accumulateTimeRange | integer | 否   | 累计时间范围(当hasAccumulate=1时必填) | 30  |
| continuousCount     | integer | 否   | 连续异常次数(当hasAccumulate=0时必填) | 3   |


json格式：
~~~json
{
  "singlePropertyRule": [{
    "symbol": "OR",
    "property": "t1",
    "lowValue": 1,
    "expression1": "lt",
    "highValue": 10,
    "expression2": "lt"
  },{..}],
  "doublePropertyRule": [{
    "symbol": "AND",
    "leftProperty": "t1",
    "rightProperty": "t2",
    "expression": "lt"
  },{..}],
  "frequency": {
  "enabled": 1,
  "hasAccumulate": 1,
  "accumulateCount": 5,
  "accumulateTimeRange": 30,
  "continuousCount": 3
}
}
~~~

#### 3. 企业违规预警config字段描述

| 字段名                | 类型     | 必填  | 描述          | 示例值                 |
| ------------------ | ------ | --- | ----------- | ------------------- |
| singlePropertyRule | array  | 是   | 设备异常告警单属性规则 | -                   |
| algorithmType      | string | 是   | 算法类型        | "algorithm_1"       |
| workStatus         | array  | 是   | 工况状态数组      | ["spray", "unused"] |
| frequency          | object | 是   | 设备异常告警频率配置  | -                   |
singlePropertyRuley与frequency同设备异常预警config字段描述

json格式：
~~~JSON
{
  "singlePropertyRule": [{
    "symbol": "OR",
    "property": "t1",
    "lowValue": 1,
    "expression1": "lt",
    "highValue": 10,
    "expression2": "lt"
  },{..}],
  "algorithmType": "algorithm_1",
  "workStatus": ["spray", "unused"],
  "frequency": {
  "enabled": 1,
  "hasAccumulate": 1,
  "accumulateCount": 5,
  "accumulateTimeRange": 30,
  "continuousCount": 3
}
}
~~~

## 二. 预警上报数据(以汽修为例)

### 主题
`RTO/warning_data/{设备编号}

### 数据格式

| 字段名       | 类型     | 必填  | 描述                        | 示例值                   |
| --------- | ------ | --- | ------------------------- | --------------------- |
| alarmId   | string | 是   | 预警规则ID                    | ""                    |
| alarmTime | string | 是   | 预警触发时间                    | "2025-09-09 11:11:11" |
| data      | object | 是   | 预警相关数据内容，主要为判断预警产生的原始数据字段 | {"xx_temperature":1}  |
