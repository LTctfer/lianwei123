# 西门子S7协议PLC数据读取系统

## 系统概述

本系统使用西门子专用的S7协议直接与西门子PLC通信，无需Modbus网关，提供更高效、更稳定的数据读取性能。

## 🏭 支持的PLC型号

### 完全支持
- **S7-200系列** (需要以太网模块)
- **S7-300系列** (需要CP343-1等通信模块)
- **S7-400系列** (内置以太网接口)
- **S7-1200系列** (内置以太网接口)
- **S7-1500系列** (内置以太网接口)
- **LOGO! 0BA7/0BA8** (内置以太网接口)

### 连接参数配置
| PLC系列 | 机架号(Rack) | 插槽号(Slot) | 说明 |
|---------|--------------|--------------|------|
| S7-1200/1500 | 0 | 1 | 默认配置 |
| S7-300/400 | 0 | 2 | CPU插槽 |
| S7-200 | 0 | 1 | 通过以太网模块 |

## 🚀 快速开始

### 1. 安装依赖环境

```bash
# 自动安装S7环境
python install_s7.py

# 或手动安装
pip install python-snap7
```

### 2. PLC配置

#### TIA Portal配置 (S7-1200/1500):
1. 打开TIA Portal项目
2. 选择PLC设备 → 属性
3. 进入"保护与安全" → "连接机制"
4. ✅ 启用"允许来自远程对象的PUT/GET通信访问"
5. 设置PLC IP地址 (如: 192.168.0.1)
6. 下载配置到PLC

#### STEP 7配置 (S7-300/400):
1. 打开STEP 7项目
2. 配置硬件 → CPU属性
3. ✅ 启用"PUT/GET通信"
4. 设置IP地址和子网掩码
5. 下载配置到PLC

### 3. 运行系统

```bash
# 测试S7连接和配置
python test_s7.py

# 读取PLC数据
python s7_plc_reader.py
```

## 📊 S7地址格式

### 数字量地址

| 格式 | 说明 | 示例 | 数据类型 |
|------|------|------|----------|
| %Q0.0 | 输出位0.0 | %Q0.0, %Q0.1 | BOOL |
| %I0.1 | 输入位0.1 | %I0.0, %I0.7 | BOOL |
| %M1.1 | 标志位1.1 | %M0.0, %M1.1 | BOOL |

### 字节/字/双字地址

| 格式 | 说明 | 示例 | 数据类型 |
|------|------|------|----------|
| %QB0 | 输出字节0 | %QB0, %QB1 | BYTE |
| %QW0 | 输出字0 | %QW0, %QW2 | WORD |
| %QD0 | 输出双字0 | %QD0, %QD4 | DWORD |
| %IB1 | 输入字节1 | %IB0, %IB1 | BYTE |
| %MW100 | 标志字100 | %MW100, %MW102 | WORD |
| %MD200 | 标志双字200 | %MD200, %MD204 | DWORD |

### 数据块地址

| 格式 | 说明 | 示例 | 数据类型 |
|------|------|------|----------|
| %DB1.DBX0.0 | DB1位地址0.0 | %DB1.DBX0.0 | BOOL |
| %DB1.DBB0 | DB1字节地址0 | %DB1.DBB0 | BYTE |
| %DB1.DBW0 | DB1字地址0 | %DB1.DBW0 | WORD |
| %DB1.DBD0 | DB1双字地址0 | %DB1.DBD0 | DWORD |

## 🔧 系统特点

### S7协议优势
✅ **原生协议**: 西门子PLC的原生通信协议，性能最优
✅ **无需网关**: 直接与PLC通信，无需Modbus网关
✅ **高速读取**: 比Modbus协议速度更快
✅ **稳定可靠**: 工业级通信协议，稳定性极高
✅ **丰富功能**: 支持所有S7数据类型和地址格式

### 支持的数据类型
- **BOOL**: 布尔值 (1位)
- **BYTE**: 字节 (8位无符号)
- **WORD**: 字 (16位无符号)
- **DWORD**: 双字 (32位无符号)
- **INT**: 整数 (16位有符号)
- **DINT**: 双整数 (32位有符号)
- **REAL**: 实数 (32位IEEE754浮点)
- **TIME**: 时间 (32位毫秒)

## 📋 使用示例

### 基本读取

```python
from s7_plc_reader import S7PLCReader

# 创建S7读取器
reader = S7PLCReader(ip="192.168.0.1", rack=0, slot=1)

# 连接PLC
if reader.connect():
    # 读取单个标签
    result = reader.read_tag("输出1", "%Q0.0", "Bool")
    print(f"输出1状态: {result['value']}")
    
    reader.disconnect()
```

### 批量读取CSV标签

```python
# 直接读取CSV中的所有标签
reader = S7PLCReader(ip="192.168.0.1")
results = reader.read_csv_tags("PLCTags.csv")

for result in results:
    print(f"{result['name']}: {result['value']}")
```

## 🛠️ 故障排除

### 常见问题及解决方案

#### 1. 连接失败
```
错误: S7连接失败
解决方案:
- 检查PLC IP地址是否正确
- 确认PLC启用了PUT/GET通信
- 验证机架号和插槽号
- 检查网络连通性: ping 192.168.0.1
```

#### 2. 访问被拒绝
```
错误: Access denied
解决方案:
- 在TIA Portal中启用"PUT/GET通信访问"
- 检查PLC保护级别设置
- 确认没有其他程序占用连接
```

#### 3. 地址格式错误
```
错误: 不支持的S7地址格式
解决方案:
- 检查地址格式是否正确
- 确认数据块是否存在
- 验证地址范围是否有效
```

#### 4. snap7库问题
```
错误: 未安装snap7库
解决方案:
- 运行: python install_s7.py
- 手动安装: pip install python-snap7
- 下载snap7动态库到系统路径
```
