# 污染源溯源系统

## 项目概述

基于多源监测数据的污染源溯源系统，通过遗传算法和模式搜索算法结合，实现污染源位置的精确反算，并通过正向传播模型验证反算准确度。

## 系统特点

- **多源数据融合**: 整合风向、风速、污染物浓度、湿度等多维监测数据
- **智能反算算法**: 采用遗传-模式搜索混合算法，提高溯源精度
- **实时验证机制**: 通过正向传播路径预测与实测数据比对验证
- **可视化界面**: 提供直观的Web操作界面和结果展示
- **三色预警系统**: 根据污染程度自动分级预警

## 技术架构

### 核心算法
- **遗传算法**: 全局搜索污染源可能位置
- **模式搜索**: 局部优化提高精度
- **高斯烟羽模型**: 污染物传播模拟
- **数据融合算法**: 多源数据整合处理

### 系统组件
- **数据处理模块**: 监测数据清洗和预处理
- **溯源算法模块**: 污染源位置反算
- **传播模拟模块**: 正向污染物扩散预测
- **验证评估模块**: 反算结果准确度评估
- **可视化模块**: 结果展示和交互界面
- **预警系统**: 三色分级预警机制

## 快速开始

### 环境要求
- Python 3.8+
- NumPy, SciPy, Pandas
- Matplotlib, Plotly
- Flask (Web界面)
- scikit-learn

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行系统
```bash
python app.py
```

访问 http://localhost:5000 查看Web界面

## 使用说明

1. **数据上传**: 上传监测站数据文件(CSV格式)
2. **参数配置**: 设置算法参数和环境条件
3. **溯源分析**: 启动污染源反算过程
4. **结果查看**: 查看溯源结果和验证报告
5. **预警管理**: 查看三色预警状态

## 数据格式

监测数据CSV文件格式：
```csv
时间,监测站ID,经度,纬度,PM2.5浓度,风速,风向,湿度,温度
2024-01-01 00:00:00,ST001,116.3974,39.9093,45.2,3.5,180,65,15.2
```
