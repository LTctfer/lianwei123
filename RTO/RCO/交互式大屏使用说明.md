# 🚀 RTO/RCO交互式监控大屏使用说明

## 📋 概述

本系统是一个全新的交互式监控大屏，提供实时数据生成、可视化展示和交互功能。保持了原有的预警规则不变，只对可视化部分进行了全面升级。

## 🎯 主要特性

### 1. 实时数据生成
- **报警频率**: 5秒内1条报警 (40%概率)
- **数据更新**: 每2秒更新一次
- **数据完整性**: 包含所有监控参数
- **历史记录**: 自动保存最近100条数据

### 2. 交互式界面
- **可点击模块**: 所有面板都支持点击交互
- **详情弹窗**: 点击模块查看详细信息
- **悬停效果**: 鼠标悬停显示动态效果
- **响应式布局**: 适配不同屏幕尺寸

### 3. 可视化功能
- **实时趋势图**: 动态显示数据变化趋势
- **状态指示器**: 直观显示设备运行状态
- **报警轮播**: 自动轮播显示报警信息
- **颜色编码**: 根据严重程度使用不同颜色

## 🚀 快速开始

### 方法一：使用启动脚本（推荐）

```bash
python start_interactive_dashboard.py
```

### 方法二：使用主程序

```bash
python warning_system.py
```

然后选择选项 `2` 启动实时监控大屏

## 🚨 故障排除

### 常见问题

**Q: 页面无法访问？**
A: 检查端口是否被占用，尝试更换端口号

**Q: 数据不更新？**
A: 检查浏览器控制台是否有JavaScript错误

**Q: 报警频率太低？**
A: 调整 `random.random() < 0.4` 中的概率值

**Q: 界面显示异常？**
A: 清除浏览器缓存，刷新页面

### 调试模式
在浏览器中按F12打开开发者工具：
- **Console**: 查看JavaScript错误
- **Network**: 检查API请求
- **Elements**: 检查HTML结构
