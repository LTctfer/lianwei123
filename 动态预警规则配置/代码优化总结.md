### 3. **简化数据清洗逻辑**
**优化前**：
```python
# 去除空值
df_clean = df_clean[df_clean[col].notna()]
# 去除0值
df_clean = df_clean[df_clean[col] != 0]
# 去除负值

```

**优化后**：
```python

```
